# Предложка MIKLYXASHOW

Готовый веб-проект для публикации на GitHub Pages. Внешний вид и основные разделы вдохновлены структурой сайта-примера: лента, сортировка, фильтры, поиск, категории, карточки, голоса, просмотренные публикации и модерация.

## Что работает
- Лента предложений, сортировка «Лучшее / Новое».
- Фильтры по статусу, категории, периоду и типу.
- Поиск по названию и описанию.
- Регистрация и вход по email через Supabase.
- Добавление предложения по ссылке или загрузка видео/изображения.
- Голоса пользователей (один голос на публикацию).
- Модерация: одобрить, отклонить, отметить просмотренным.
- Тёмная и светлая темы.
- Адаптация под мобильные устройства.

## Важно: демо и настоящий режим
Без настройки Supabase сайт запускается в демо-режиме. В нём можно посмотреть интерфейс, фильтры и тестовые карточки; локальные отправки сохраняются только в браузере и не видны другим людям.

Для общих аккаунтов, файлов, голосов и публикаций подключите Supabase:
1. Создайте проект в Supabase.
2. Откройте SQL Editor и выполните `supabase_setup.sql`.
3. В Project Settings → API скопируйте Project URL и anon/public key.
4. Вставьте их в `config.js` в поля `SUPABASE_URL` и `SUPABASE_ANON_KEY`.
5. В Supabase → Authentication → URL Configuration укажите URL GitHub Pages в Site URL и Redirect URLs.
6. Зарегистрируйте аккаунт стримера.
7. В SQL Editor назначьте ему права администратора, заменив email:
   ```sql
   update public.profiles
   set is_admin = true
   where id = (select id from auth.users where email = 'EMAIL_СТРИМЕРА');
   ```

`anon/public key` предназначен для браузера; не вставляйте `service_role` key в `config.js` или GitHub.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий, например `miklyxashow-suggest`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `config.js`, `supabase_setup.sql` и `README_RU.md`.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. После публикации откройте URL, который покажет GitHub Pages.

## Безопасность и модерация
- Не выдавайте никому `service_role` key.
- Убедитесь, что SQL-политики включены.
- Проверяйте материалы перед тем, как показывать их на эфире.
- Разрешайте загрузку только материалов, которыми отправитель имеет право делиться.
- Для публичного проекта стоит добавить лимиты частоты отправки, жалобы и расширенную защиту от спама на серверной стороне.

## Что нужно доделать перед запуском
- Вставить URL и anon key Supabase в `config.js`.
- Добавить настоящий аватар/баннер стримера и его официальные ссылки, если он их предоставит.
- Настроить домен/URL в Supabase Auth.
- Проверить проект тестовыми аккаунтами.
